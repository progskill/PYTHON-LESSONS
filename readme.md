# PYTHON SESSIONS
### Uploading Code to GitHub

#### Steps

- `git init`
- `git add .`
- ` git commit -m "commit message"`
- `git remote add origin https://github.com/........."`
- ` git push -u origin master or main`

### Updating an Existing Repository

#### Steps

- `git add .`
- ` git commit -m "commit message"`
- ` git push -u origin master or main`
